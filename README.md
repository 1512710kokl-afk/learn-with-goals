# 目标导向学习 · Learn with Goals

一个可以反复调用的个人学习教练技能。把“我想学这个”变成明确的学习目标，再通过基础诊断、小步讲解、练习反馈、迁移和复测带你推进。

你会一直知道：**要学会什么、现在掌握到哪里、下一步做什么。**

## 开始使用

安装后，在 Codex 中输入：

```text
$learn-with-goals 我想学 Excel 透视表，希望能独立分析一张订单表。
```

也可以带上基础、时间或材料：

```text
$learn-with-goals 我想学 Python，完全零基础，每天有30分钟，
希望能自己把几份 CSV 合并并找出重复记录。先诊断我需要哪些基础。
```

```text
$learn-with-goals 带我学习这篇文章。我希望能用自己的话解释核心观点，
并判断它能否用到我的工作里。请先确认实际能读取哪些内容。
```

## 它怎样带你学习

| 方法 | 在学习中怎么用 |
|---|---|
| 学习阶梯 | 根据基础拆出必要前置知识、阶段成果和过关标准 |
| 重点取舍 | 从你的任务倒推核心内容，不要求先学完整本教材或全部菜单 |
| AI考官 | 通常一次一道题，等你先尝试，再依据答案调整 |
| 一页速查表 | 先鼓励你凭记忆概括，再补齐关键关系、步骤和常见错误 |
| 资源筛选 | 选少量可信主资料，并说明怎么用、练什么 |
| 费曼式复述 | 让你自己解释、举例、说明边界，暴露模糊之处 |

卡住时逐级提供提示，必要时演示；随后换一道题检查。已经会的内容可以跳过，目标或时间改变时会调整路径。

它会区分“提示下能完成”“独立通过”“延迟复测通过”，并在结束前回到最初目标做综合验收。你明确需要答案或批量练习时，也会尊重你的选择。

## 安装到 Codex

可以让内置安装器从这个仓库安装：

```text
$skill-installer 从 https://github.com/1512710kokl-afk/learn-with-goals 安装根目录的技能，技能名为 learn-with-goals。
```

也可以手动安装。macOS / Linux 示例：

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/1512710kokl-afk/learn-with-goals.git ~/.agents/skills/learn-with-goals
```

如果已有同名目录，请先检查已有版本，避免覆盖。安装后如果技能没有出现，可以重启 Codex。

本仓库根目录就是技能目录，包含：

```text
learn-with-goals/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── README.md
```

本技能由指令组成，不需要额外脚本、连接器或单独的 API 密钥。访问外部材料的能力取决于所用环境。

技能目录和安装方式参见 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。

## 暂停与续学

学习暂停或结束时，会生成一张续学卡，记录目标、资料、已经验证的能力、卡点和下一步。

换聊天后，可以把续学卡贴过去：

```text
$learn-with-goals 根据下面这张续学卡接着带我学，先检查上次的薄弱点：
[粘贴续学卡]
```

默认在对话里提供卡片；要求存档时才写入指定位置。它不会自动保存全局学习历史，也不会自动创建提醒。

## 当前状态

这是可使用的初版，已通过技能结构和元数据校验。实际教学效果仍需在真实学习过程中持续验证，不承诺固定倍速或“十倍学习”。

面对长书或视频时，会先确认可读取范围；尚未读取的内容不会被当作已经掌握的资料。判断答案时优先依据原文、正确解答、运行结果或明确的评价标准。

## 方法来源

欢迎通过 Issues 提交实际使用中遇到的问题，尤其是目标不明确、讲解节奏不合适、提示过多或验收不足的情况。
